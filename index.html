SELF-HOSTED UBUNTU SOFTWARE

Your scale, monitored locally.

Scale Local receives supported Etekcity ESF14 Bluetooth scale advertisements on an Ubuntu computer, saves final weights in local SQLite history, and provides a read-only dashboard and CSV export.

Local capture does not require a Google account. Optional Google Health sharing is off until the installation owner authorizes Google access and explicitly enables uploads.

Read the privacy policy

What the application does

  • Continuously monitors explicitly selected, supported Bluetooth scales while the Ubuntu computer is awake and its adapter is available.
  • Keeps local measurement history, supports kilogram/pound display, and exports local records as CSV.
  • Optionally uploads newly saved final weights strictly over 140 lb to the user's authorized Google Health account.
  • Shows upload progress and errors. Uncertain uploads are held for review rather than automatically retried in a way that could create duplicates.

The weight cutoff is not person identification. The owner must ensure that readings from a selected scale belong to the connected Google account.

Optional Google Health integration

The installed Ubuntu application uses Google OAuth to obtain permission. It sends only weight and measurement time, including the recorded UTC offset. It does not upload Bluetooth addresses, raw scale packets, impedance, or body-composition estimates.

The requested health-measurements write scope is broader than weight, although this application implements weight uploads only. Basic openid identity is used to bind the installation to the selected account. No health-history read, email, or profile scope is requested.

Authorization takes place through Google's sign-in page and a loopback callback on the owner's computer, optionally reached through SSH. This website does not perform sign-in, receive authorization codes, or collect measurements or tokens.

Control stays with the installation owner

Sharing can be paused or disconnected through the local command-line interface. Older unqueued history is not automatically uploaded. Disconnecting removes local authorization after confirmed revocation; it does not delete weights already sent to Google.

The default dashboard stays on localhost. Optional LAN access uses a separately configured HTTPS/password proxy. This public information site is not the dashboard and has no connection to any installation.

Contact and support

For software or privacy questions, use the project issue tracker. Issues are public: do not include measurements, device addresses, Google credentials, authorization URLs, or diagnostic logs containing personal information. For data held by an installation, contact its owner.
